Pure Go WebAssembly Engine

Engineered for reliable, high-fidelity document speech

No backend servers, no cloud fees, and no third-party telemetry. LEXIO executes all file parsing, speech coordination, and text formatting inside your device's browser using Go compiled to WebAssembly.

Native Web Speech Synthesis

Utilizes your operating system's built-in voice synthesizer (macOS, Windows, iOS, Android, Linux) with zero API costs, zero network lag, and full offline capability.

Synchronized Visual Tracking

Reads by sentence and clause rather than robotic single-word steps. The document viewer tracks active phrases in real-time with adjustable automatic centering.

Region-Wise Accent Selection

Select exact regional accents for each language: US, UK, India, Australia, Canada for English; Spain, Mexico, Argentina for Spanish; Saudi Arabia, UAE, Egypt for Arabic; Italy, Switzerland for Italian.

In-Browser Document Extraction

Extracts text from complex PDFs, Word documents, PowerPoint presentations, Excel spreadsheets, and EPUB books locally without sending a byte over the internet.

1

Import or Paste Content

2

Private by Design: Zero Server Drama

LEXIO is a 100% pure client web application executed via Go WebAssembly. It requires no Node.js runtime, connects to no backend analytics, and transmits no document contents to remote servers. All your notes, accounts, and audio settings reside entirely in your browser's private local storage.

User Manual

1. Choose a Workspace View

Use Dashboard for reading statistics, Reader for synchronized playback, and Document Inspector for outline and structure review.

2. Import or Paste Content

Open Reader, upload a supported document or paste raw text. LEXIO will parse it into a clean, phrase-tracked reading surface.

3. Tune Your Voice & Regional Accent

Select your language, regional accent (US, UK, India, Australia, Spain, Mexico, Saudi Arabia, Italy, etc.), and gender (Male or Female). Adjust speed and pitch using the smooth range sliders.

4. Synchronized Audio Playback

Click Start. Visual highlights follow the spoken sentence and automatically center the reading surface. You can also click any individual word to start reading from there.
